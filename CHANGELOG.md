# Changelog

All notable release-level changes to AI-Verse Brain are documented here.

## 0.1.0-beta.1

Public beta release candidate.

- Added reasoner-only Claude Code, Codex CLI and Hermes Agent wrappers behind the hardened Brain bridge.
- Added a read-only current-context host for safe standalone/native cognition ticks.
- Added `vendor-doctor` and `run-tick` CLI flows.
- Added portable cadence hook generation without scheduler ownership.
- Added explicit, fail-closed migration planning and safe package-metadata refresh.
- Added release/security/vendor documentation and MIT licensing.
- Added wheel clean-install smoke testing in CI.
- Removed the obsolete Phase 4 branch from push-triggered CI and disabled matrix fail-fast so one failure does not make the remaining jobs appear as misleading cancellations.

## 0.1.0-alpha.7

- Added hardened `ai-verse-brain-bridge/1.0` JSON subprocess protocol.
- Added shell-free adapter execution, bounded I/O, timeouts, environment allowlisting, request/response correlation and credential-command guards.
- Added bridge reasoner/host adapters and adapter diagnostics.
- Added a safe reference adapter and cross-platform tests.

## 0.1.0-alpha.6

- Added dry-run-first initialization and versioned installation metadata.
- Added adaptive explicit-user onboarding.
- Added state-schema upgrade guards and installation/onboarding doctor checks.
- Added native AI-Verse OS fail-closed initialization without modifying OS canonical configuration.

## 0.1.0-alpha.5 and earlier

- Built the deterministic Brain core: intent, direction, initiatives, bounded objectives, evidence-backed verification, progress/stall control, attention policy, belief freshness, staged learning, controlled strategy evolution, cadence contracts, replay-safe action boundaries and the runtime-neutral cognition pipeline.
